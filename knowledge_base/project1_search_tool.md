项目 1 的搜索工具 search_tool 定义在 tools/search.py，底层是 duckduckgo-search 库的 DDGS().text() 接口，免费、无需 API Key。它接收一个搜索关键词，取前 5 条结果，把每条的标题、摘要和来源链接拼成编号列表返回；无结果时返回"未找到相关结果，请尝试更换关键词"，网络异常时也转成可读字符串。作用是给 Agent 提供实时外部信息，弥补模型知识截止日期的限制，典型用法是"搜索 Python 最新版本"这类时效性问题。局限：DuckDuckGo 偶尔不稳定，可能返回空结果，需要换关键词重试。在改造方案中，search_tool 与新增的 rag_search 分工不同——前者查互联网上的公开实时信息，后者查本地的固定领域知识库；系统提示词需要说清各自适用场景，避免 Agent 混用。
