ReAct（Reasoning + Acting）是一种让大语言模型"边思考边行动"的 Agent 推理框架，由 Yao 等人于 2022 年提出。它的核心思想是把一次任务拆成循环往复的三步链条：Thought（推理）→ Action（行动）→ Observation（观察）。模型先在 Thought 里分析当前状态、决定下一步；再输出一个 Action 调用外部工具；环境返回工具结果作为 Observation；模型据此进入下一轮推理，直到信息足够、给出最终答案。与纯 Chain-of-Thought（只推理、不接触外部世界）相比，ReAct 的关键差别在于"行动"——模型能主动调用搜索、计算、数据库等工具获取真实数据，再基于观察继续推理，因此显著减少凭记忆编造。它擅长需要多步骤、需要外部信息的复杂任务；缺点是轮数多时延迟和 token 成本上升，且模型可能陷入重复调用。本项目 agent.py 使用 LangChain 的 create_agent，底层正是基于 LangGraph 运行的 ReAct 循环，系统提示词中"必须分步依次调用不同工具"的规则就是在约束这个循环。
