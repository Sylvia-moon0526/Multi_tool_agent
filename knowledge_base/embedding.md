Embedding（向量化）把文本映射成高维向量，使语义相近的文本在向量空间里距离更近，从而实现"按语义而非关键词"的检索。RAG 中文档和用户问题都要经过同一个 Embedding 模型，才能在同一空间里比较相似度。本项目选用 SiliconFlow 提供的 BAAI/bge-m3：它支持多语言、中文效果好、支持长达 8192 token 的输入，并同时具备稠密检索、稀疏检索与多向量能力，是中文 RAG 的常见首选。通过 langchain_openai 的 OpenAIEmbeddings 类、传入 model="BAAI/bge-m3" 与 SiliconFlow 的 base_url 即可调用，无需额外账号。使用要点：建库与检索必须用同一个 Embedding 模型，否则向量不在同一空间，检索结果会完全失真；更换模型后必须重建整个索引。此外，bge-m3 对中英混合文本也能稳定编码，适合本项目这种中文笔记为主、夹杂英文 API 名称与函数名的语料，检索时不会因为术语是英文就失效。
