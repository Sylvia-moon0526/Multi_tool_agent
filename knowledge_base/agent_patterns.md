Agent 模式指让大模型自主完成任务的若干组织方式。常见几类：一是 ReAct，边推理边调用工具，适合需要外部信息的多步任务；二是 Plan-and-Execute（先规划再执行），先生成完整计划再逐步执行，适合步骤清晰、可提前拆解的任务；三是 Reflection（反思），让模型对自身输出打分并迭代改进，适合写作、代码等质量敏感场景；四是 Tool-use（工具使用），核心是把外部能力封装成工具供模型调用；五是 Multi-Agent（多智能体），多个角色分工协作。选择依据是任务性质：需要实时数据用 ReAct，需要全局规划用 Plan-and-Execute，需要高质量输出用 Reflection。本项目属于典型的"ReAct + Tool-use"组合：三个（改造后四个）工具注册给 Agent，由模型在循环中自主选择，写死在 system prompt 里的规则则用来约束这个自主性，避免漏调或乱调工具。
