系统提示词（system prompt）决定 Agent 的角色、可用工具和行为边界，是让工具型 Agent 稳定工作的关键。有效的系统提示词通常包含四部分：角色定位（"你是一个多工具助手"）、工具清单与各工具用途、明确的工作规则（何时必须调用哪个工具、多步骤任务如何拆分）、输出要求（语言、是否带来源、是否写单位）。本项目的 system prompt 就是范例：它列出 search_tool、calculator_tool、get_weather 三个工具的用途，并写死三条规则——多步骤任务必须分步依次调用不同工具、需要数值计算时必须调用计算器、回答用中文并带关键数值和单位。原因模型天然倾向"凭记忆直接答"，不写规则就会出现"AI 存在感弱"的问题。RAG 接入后还要再加一条：知识性问题优先检索知识库、基于来源回答、不要编造。
