在 LangChain 中，工具通常用 @tool 装饰器把一个普通 Python 函数注册成 Agent 可调用的工具。设计时三个要点：一是函数签名与类型注解——参数名和类型会被转换成模型看到的 JSON Schema，命名要清晰，必要时在 docstring 里给出输入示例；二是 docstring——它既是函数文档，也是"告诉模型什么时候该用这个工具"的说明，写清适用场景能显著提高工具被调用的准确率，本项目 rag_search 的 docstring 就明确写了"涉及技术概念、项目细节时必须调用，不要凭记忆编造"；三是返回值与容错——工具应把异常转成可读字符串返回，而不是抛出中断循环，本项目三个工具都遵循"出错返回提示语"的约定。工具设计的质量，往往比模型本身更决定 Agent 表现。
