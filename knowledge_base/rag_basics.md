RAG（Retrieval-Augmented Generation，检索增强生成）是一种把"外部知识检索"与"大模型生成"结合的技术，用来解决模型知识过时、容易幻觉、无法覆盖私有领域的问题。标准流程分三阶段：一是索引（Indexing），把文档加载、切分、向量化后存入向量数据库；二是检索（Retrieval），把用户问题也向量化，在库中按相似度找出最相关的若干片段；三是生成（Generation），把检索到的片段连同问题一起拼进提示词，交给 LLM 生成答案。这样模型的回答"有据可依"，并且可以标注来源。RAG 的价值在于：知识更新只需重建索引，不必重新训练模型；回答可溯源，便于核验。它的效果取决于两端——检索端能否召回正确片段，生成端能否忠实于检索内容。本项目的改造方案就是给现有 Agent 增加 rag_search 工具，把这套流程接入 ReAct 循环。
