项目 1 在 agent.py 里为 Agent 写了系统提示词，核心是三条工作规则，用来约束 ReAct 循环的自主性。规则一：任务包含多个连续步骤（如"先搜索再计算""查天气然后计算"）时，必须分步依次调用不同工具——先用前面的工具拿数据，再用 calculator_tool 对数据做计算，最后整合结果，不能只用一个工具就结束。规则二：只要涉及数值计算（倍数、总和、增减结果），一律调用 calculator_tool，不要心算。规则三：直接回答前用简洁中文总结，把关键数值和单位写进回答。这些规则针对的是实际痛点：模型默认倾向凭记忆直接作答，导致多工具组合任务只调用一个工具、或回答缺少数值细节。RAG 改造后需追加第四条：知识性、项目细节类问题优先用 rag_search 检索并注明来源，不要编造。
