项目 1 的计算器工具 calculator_tool 定义在 tools/calculator.py，输入一个数学表达式字符串，返回"表达式 = 结果"。底层用 Python 的 eval()，但做了安全沙箱：把 __builtins__ 清空，只通过 allowed_names 白名单放行 abs、round、min、max、sum、pow、int、float 和 math 模块，因此 __import__('os') 之类的调用会被挡住，支持 2+3、math.sqrt(16)、2**10 等常见运算。异常不抛出，而是返回"计算失败: ...请检查表达式是否正确"，避免中断 Agent。面试要点：这套白名单能挡住绝大多数直接调用，但理论上仍可能被属性链（如 __class__.__mro__）逃逸，生产环境应改用 asteval 或独立沙箱进程；项目保留 eval 是为了展示安全沙箱的设计思路。在 Agent 规则中，"需要数值计算时必须调用 calculator_tool"被写死，防止模型心算出错。对应的测试用例 test_calculator_tool 让 Agent 计算 123 * 456 + 789，并断言输出里出现正确答案 56877，既验证了工具调用，也验证了结果回填到最终回答。
