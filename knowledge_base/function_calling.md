Function Calling（工具调用）是大模型提供的一种结构化输出能力：开发者把可用工具以 JSON Schema 的形式描述给模型，模型在需要时不再输出自然语言，而是输出一个结构化的 tool_call（函数名 + 参数）。应用层解析这个调用、真正执行函数、再把结果作为消息回喂给模型，模型据此生成下一步。它本质上是"模型提出意图、程序负责执行"的分工。在 LangChain 中，工具通过 @tool 装饰器定义，框架自动把函数签名转换成模型能理解的 Schema，并把调用与回喂流程封装在 Agent 执行图里，开发者无需手写解析逻辑。Function Calling 让 LLM 从"只能聊天"变成"能操作外部系统"，是构建工具型 Agent 的基石。需要注意：模型只负责决定"调哪个函数、传什么参数"，函数本身是否安全、参数是否校验、异常如何处理，都由应用代码负责。
