LangGraph 是 LangChain 生态中用于编排有状态、多步骤 Agent 的图框架。它把工作流抽象成"节点（Node）+ 边（Edge）+ 状态（State）"：节点是一段计算或一个工具调用，边决定流转方向，状态在节点间传递。相比链式（Chain）的单向线性执行，LangGraph 的关键优势是支持循环（loop）和条件分支——这正是 ReAct"思考—行动—观察"反复迭代所需要的。此外它提供状态持久化（checkpoint）、中断与人工介入（Human-in-the-loop）、流式输出等能力，适合长流程、可恢复的复杂 Agent。用一句话概括：Chain 适合固定的线性流程，LangGraph 适合需要模型自主决定下一步、可能反复迭代的流程。本项目虽然只调用 create_agent，没有手写图，但底层执行就是 LangGraph 的 ReAct 图，这正是"多工具分步调用"能稳定工作的原因。
