很多人把 ReAct 和 Function Calling 混为一谈，其实二者不在同一层。Function Calling 是模型层的能力/接口机制，规定"模型如何输出一个结构化工具调用"；ReAct 是应用层/提示层的推理框架，规定"模型如何组织思考、行动、观察的多轮循环"。可以这样理解：Function Calling 提供了 ReAct 循环里"Action"这一步的实现手段，而 ReAct 决定了何时行动、如何根据观察继续推理。没有 Function Calling，也可以用"输出特定格式文本 + 正则解析"实现 ReAct，只是更脆弱；有了 Function Calling 却不用 ReAct 框架，模型也能单次调用工具，但难以稳定完成多步骤组合任务。面试中常见的回答：ReAct 是"方法论"，Function Calling 是"工具/通道"。本项目两者结合——create_agent 用 ReAct 组织循环，@tool 工具靠模型的结构化调用能力被触发。
