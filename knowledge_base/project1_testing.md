项目 1 用 pytest 做测试，测试文件是 tests/test_agent.py。它用 @pytest.fixture 构建一个复用的 agent 实例，然后覆盖三类场景：test_search_tool 让 Agent 搜索"LangChain 是什么"，断言回复长度大于 10，间接验证搜索工具被调用；test_calculator_tool 让 Agent 计算 123 * 456 + 789，断言结果里出现正确答案 56877；test_multi_tool 是集成测试，让 Agent"搜索 Python 最新版本号，再计算版本号数字之和"，断言回复较长，验证多工具分步组合能跑通。这套断言偏"端到端行为"而非精确匹配，好处是不依赖外部搜索结果的具体内容。运行方式是 pytest tests/ -v，也可以指定单一用例运行。这套测试的价值在于：不依赖某个具体搜索结果，而是检验 Agent 端到端行为是否符合预期。改造方案会新增 tests/test_rag.py，用"回答必须包含'来源'"这类断言验证 RAG 工具被真正调用且结果可溯源，把"可溯源"这一 RAG 核心特性变成可自动检查的测试。
