SiliconFlow 是国内的一家模型推理服务平台，提供与 OpenAI 兼容的 API，本项目所有 LLM 与 Embedding 调用都走它。接入方式：把 base_url 设为 https://api.siliconflow.cn/v1，api_key 从环境变量 SILICONFLOW_API_KEY 读取，再用 init_chat_model(model_provider="openai") 或 OpenAIEmbeddings 调用，就能复用 LangChain 的标准接口。这样设计的好处是只用一个 Key 就能同时跑聊天模型（Qwen/Qwen3.5-9B）和 Embedding 模型（BAAI/bge-m3），国内访问延迟低、按量计费成本低，且可随时换其他模型。配置要点：Key 不要写进代码，用环境变量或 .env 文件管理；base_url 必须带 /v1；换模型后要同步检查上下文长度、工具调用支持等能力差异。天气和搜索工具不依赖该 Key，属于免费公开接口。环境变量缺失时 agent.py 的 os.environ["SILICONFLOW_API_KEY"] 会直接抛 KeyError，README 的常见问题里专门给了各平台的设置命令，这也是新人运行项目最容易踩的坑。
