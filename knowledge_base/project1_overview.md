项目 1（Multi_tool_agent）是一个基于 LangChain + LangGraph 的 ReAct 多工具 Agent，核心能力是自主决策、按需组合异构工具完成多步骤任务。整体结构：main.py 是命令行交互入口；agent.py 负责装配——用 init_chat_model 初始化 SiliconFlow 上的 Qwen/Qwen3.5-9B 模型，注册工具并用 create_agent 构建 Agent；tools/ 目录用 @tool 定义三个工具：search_tool（DuckDuckGo 联网搜索）、calculator_tool（安全 eval 数学计算）、get_weather（Open-Meteo 天气查询）；tests/test_agent.py 用 pytest 覆盖单工具与多工具组合。技术栈特点是"只有一个必须的环境变量 SILICONFLOW_API_KEY"，搜索和天气都免 Key。改造方案要在此基础上新增第四个工具 rag_search，接入本地技术文档知识库，不改 ReAct 主循环，只增加两个文件并在 agent.py 注册一行，属于最小改动的增量升级。项目的目标读者是面试场景，README 里已经写清了工具原理、设计决策（为什么用 DuckDuckGo、为什么用 eval）和常见问题，改造后的 RAG 部分也应沿用这种"讲清楚为什么"的叙事风格，而不是只堆代码。
