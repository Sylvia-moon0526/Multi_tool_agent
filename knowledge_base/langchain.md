LangChain 是一个用于构建 LLM 应用的组件化框架，目标是把"模型调用、提示组织、工具执行、记忆管理、检索增强"等常见环节标准化、可组合。核心模块包括：Models（统一封装各类 LLM/Chat 模型接口）、Prompts（模板与少量示例）、Chains（把多个组件串成流程，LCEL 表达式）、Tools 与 Agents（让模型选择并调用工具）、Retrieval（文档加载、切分、向量化、检索）。它的价值在于屏蔽不同模型供应商的接口差异——本项目通过 init_chat_model 配 model_provider="openai" 与自定义 base_url，就能把 SiliconFlow 上的 Qwen 模型接入同一套 Agent 代码。LangChain 提供 create_agent 作为构建 Agent 的统一入口，底层由 LangGraph 驱动。选型理由通常是生态成熟、文档丰富、替换成本低：换模型或换向量库，往往只改一两行配置。
