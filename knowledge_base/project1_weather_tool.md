项目 1 的天气工具 get_weather 定义在 tools/weather.py，底层用 Open-Meteo 的免费公开 API，无需任何 API Key。它分两步：先请求 geocoding-api.open-meteo.com/v1/search 把城市名解析成经纬度，再请求 api.open-meteo.com/v1/forecast 带 current_weather=true 获取当前天气。工具内置 18 个中文城市别名映射（如"北京"→beijing），因此中文、英文城市名都能用；返回的 WMO 天气码通过一个映射表转成中文描述（0 晴、61 小雨、95 雷阵雨等）。输出包含温度、天气状况和风速（km/h）。容错设计完善：空输入、找不到城市、请求超时、网络异常都返回可读提示语，不抛异常打断 Agent 循环。这个工具常被用来出"项目1的天气工具用了什么 API？"这类检索题，答案要点是 Open-Meteo、Geocoding + Forecast 两个接口、免费无 Key。另一个常见追问是"为什么天气工具不需要环境变量"——因为 Open-Meteo 是公开接口，全项目真正必须的 Key 只有 SiliconFlow 那一个，这也是 README 里强调的"一个 Key 全功能运行"设计。
